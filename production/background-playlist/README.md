# 夏コラボ背景動画：13本のランダム再生

ユーザーが完成させた13本を、トップページの背景動画として使用します。

- 13本を一度ずつ再生するたびに並べ替えます。一巡の最後と次の最初も同じ動画になりません。
- 再生の途中で停止した場合は、同じ動画の続きから再開します。
- 別タブを見ている間は一時停止します。端末の「視差効果を減らす」設定では暗い背景を表示します。
- 色調・暗さ・光のにじみ・粒子・周辺減光・スクロールに連動する移動と拡大は既存の指定を引き継ぎます。
- 再生速度も従来どおり0.72倍です。13本の一巡は約4分13秒になります。
- 各動画の冒頭と末尾では従来のフェードを使い、切り替えや読み込み中は暗い背景を表示します。旧動画の静止画は背景から削除しました。
- 読み込めない動画は飛ばします。すべて読み込めない場合は暗い背景を表示し、再生ボタンで再試行できます。
- 動画自体は無音です。サイトのBGMは従来の操作で再生します。

## 配信用動画

`public/media/background-clips/clip-01.mp4`〜`clip-12.mp4` は、依頼文に記載された順で採番しています。10番は作品19「SUMMER FESTIVAL」の8秒の新動画「image-to-video-1789011226634.mp4」に差し替え済みです。12番が「寧動画.mp4」です。13番は作品20『波打ち際、現行犯。』の追加動画「image-to-video-1788968613586.mp4」です。この番号は、以前のプロンプト資料のカット番号との対応を示すものではありません。

元動画は変更せず、最大1920×1080のH.264に、元の縦横比を維持して変換しました。動画10は1632×1080です。全フレームと各動画のフレームレート・尺を保持し、配信しやすい形式にしています。音声トラックは取り除きました。

13本合計：元動画213.04 MB → 配信用98.16 MB（約54%削減）。ページを開いたときは再生する1本だけを読み込み、終了に合わせて次を読み込みます。

元ファイルと配信用ファイルの対応、尺、フレーム数、容量、SHA-256は `manifest.json` に記録しています。

## 実装

再生順・停止・復帰・エラー時の処理は `app/backgroundPlaylist.ts`、トップページへの接続は `app/page.tsx` です。`app/globals.css` の既存エフェクトを維持し、旧背景静止画用の指定は削除しています。GitHub Pagesのサブパスにも対応しています。
